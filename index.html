📱 Mobile Phone (Android / iOS)

  • PocketPal AI: Settings → Local Models → + → Load from phone → pick .gguf
  • ChatterUI: Manage → Models → + → Import GGUF → Template: Qwen3 / ChatML
  • Termux: sh scripts/fetch-model.sh kilo (optional)
  • Context: 4096 (2048 on 2–3 GB phones)
  • Threads: Number of big CPU cores

💻 Desktop PC (Windows / Mac / Linux)

  • LM Studio: My Models → Import → select .gguf
  • Ollama: ollama create pocket-ai -f Modelfile.ollama
  • Context: 4096, GPU offload as available
  • Same files: One GGUF runs everywhere
